# Security Policy

## Reporting a Vulnerability

Security is a fundamental priority for this cloud platform infrastructure. If you discover a security vulnerability, please report it privately rather than opening a public issue.

### Private Reporting Channel
* **GitHub Private Security Advisory:** [Report a Vulnerability](https://github.com/sanjiivsingh/azure-enterprise-landing-zone-terraform/security/advisories/new)
* **Direct Contact:** [https://github.com/sanjiivsingh](https://github.com/sanjiivsingh)

Please include:
1. Description of the vulnerability or misconfiguration
2. Reproduction steps or Terraform code snippet
3. Potential impact on Azure infrastructure or perimeter boundaries

We will acknowledge receipt within 48 hours and work on remediation promptly.
